# Scanner-layer equivalent mutation suppression (suppress-when)

We deliberately drop constructively equivalent mutation sites at scan time so they never enter the run set or the score denominator. mutate4lua attaches `suppress-when` predicates to each mutation rule (clj-mutate shape): before `add_site`, predicates see `node` / `parent` / `source` / `replacement` and may skip the site. This changes site-selection semantics and raises score by shrinking the denominator; false suppression (skipping a killable site) is the only correctness surface and is gated by fixtures plus a monopoly `number.lua` gold standard (must cover the nine F3 equivalents; must not cover the twenty-six load-phase killables). Rejected: engine-side mark-and-skip (extra bookkeeping, same runtime win), line/text fingerprints (not a mechanism), and silent suppression (score jumps with no audit trail). CLI stays flag-free; diagnostics gain one summary line `suppressed equivalent sites: N`. Runner contract unchanged — ADR lives in this repo. Guard after landing: 77 killed / 6 survived on the monopoly number.lua baseline.
